# 今天，我用 AI 做了一个"手机App隐私体检工具"

---

## 起因：一个朋友的疑问

朋友发来一个 App 安装包（llG-New v1.2.13），问我："这个 App 安全吗？会不会偷看我隐私？"

我看了看，一个 .apk 文件，啥也看不出来。

**于是我想：能不能让 AI 帮我分析一下？**

---

## 第一步：试试看，AI 能不能分析 APK？

我把 APK 文件丢给 AI，说："帮我看看这个 App 安不安全。"

AI 说它可以写一个分析脚本。几分钟后，一个命令行工具诞生了。

**分析结果让我吃了一惊：**

| 发现 | 说明 |
|------|------|
| 🔴 录音权限 | App 可以偷偷录音 |
| 🔴 GPS定位 | 随时知道你在哪 |
| 🔴 读手机号/IMEI | 获取你的设备唯一标识 |
| 🔴 读取相册 | 查看你的照片和视频 |
| 🔴 静默安装 | 可能偷偷装其他App |
| 🌐 93个网络地址 | 连接了54个不同的服务器 |

**风险评分：230分（满分100+），等级：HIGH 高风险**

---

## 第二步：但命令行太难用了

工具是做好了，但问题是：

> 每次用都要打开黑窗口敲命令，朋友根本不会用。

**我想要的效果：**
- 🖱️ 双击打开
- 📂 弹窗选文件
- 🔍 点一下开始分析
- 🌐 自动在浏览器里看到漂亮的结果

---

## 第三步：花了一下午，把工具"包装"成人人都能用的样子

用 AI 一步步改造：

**遇到的问题 & 解决：**

| 问题 | 解决 |
|------|------|
| 界面按钮点了没反应 | 修复了代码里的"变量丢失"bug |
| 报告页面打不开 | 修复了模板语法错误 |
| 分析完了浏览器不弹出来 | 改成后台线程打开浏览器 |

**最终的样子：**

```
双击启动 → 弹窗选APK → 点"开始分析" → 进度条跑完 → 浏览器自动打开报告
```

整个流程，**不用敲一行命令**。

---

## 第四步：再测一个"影视仓"App

用新工具分析第二个 App，结果同样触目惊心：

**这个 App 会：**

- 🌐 连接大量不明服务器
